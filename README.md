Cocina360 🍽️

Cocina360 is a modern restaurant ERP built with Next.js, TypeScript, Supabase, and PostgreSQL.

The platform is designed to connect waiters, kitchen staff, cashiers, and administrators in real time through a scalable web application.

Features
Role-based access
Real-time order management
Kitchen workflow system
Cashier and billing module
Restaurant table management
Dynamic menu system
PostgreSQL relational database
Responsive modern UI
Tech Stack
Next.js 16
TypeScript
Tailwind CSS
Supabase
PostgreSQL
Vision

Cocina360 aims to become a scalable and intelligent ERP solution for restaurants, integrating operations, analytics, inventory, and real-time collaboration between devices and staff.

Built with ❤️ in Colombia.
