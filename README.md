# 🍽️ Cocina360

Modern restaurant ERP system designed to connect waiters, kitchen staff, cashiers, and administrators in real time.

🌱 Description

Cocina360 is a web-based restaurant management platform focused on simplifying restaurant operations through a modern and scalable system.

The platform allows restaurants to:

🍽️ Manage restaurant tables
🧾 Create and track orders
👨‍🍳 Send orders to the kitchen in real time
💳 Handle cashier and billing workflows
📱 Access the system from multiple devices simultaneously
⚡ Synchronize data instantly using real-time technology

This project aims to become a complete digital ecosystem for restaurants, combining operational efficiency, modern UI/UX, and scalable cloud infrastructure.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/codermuisca/cocina360.git

cd cocina360
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open in browser:

```txt
http://localhost:3000
```
